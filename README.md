# RolanEstudio

Portafolio interactivo hecho con Bootstrap 5, CSS y JavaScript. Abre `index.html` en el navegador con internet.

## Efectos

- Tarjetas: `rotate`, `scale` y `translateY` con `transition`.
- Tarjeta 3D: `perspective`, `preserve-3d`, `rotateX` y `rotateY`.
- Animaciones: `aparecer` para el título, `latido` para el logo y `girar` para el loader.

El formulario es una demostración y no envía datos. Las capturas están en `capturas_portafolio.pdf`.
